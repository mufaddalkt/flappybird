# Flappy Bird — Sky Hop 🐤

A colorful Flappy Bird-style game built in HTML5, CSS, and vanilla JavaScript.

## Playing

Open `index.html` in a modern browser. No build tools required.

- **Space**, **↑**, **click**, or **tap** to flap.
- **P** to pause or resume.
- Toggle sound with the 🔊 button.
- Avoid pipes, the ceiling and the ground. Pass pipe gaps for points.
- Your best score is stored in browser local storage.

## Hosting on GitHub Pages

Choose **Settings → Pages → Deploy from a branch → main → / (root)** and save. The site is entirely static.
